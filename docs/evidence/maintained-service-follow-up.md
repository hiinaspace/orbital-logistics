# Maintained service diagnosis and display performance — 2026-10-09

The user observed long home waits, close/high-energy Tern returns, and playback
hitches. [Diagnosis, proposal and reproducible measurements](../design/maintained-service/follow-up/README.md)
record a1536-unit rollout,20 bounded alternative-transfer trials and before/after
Chrome profiles. This pass ships rendering/display optimizations; it does not
change the live service planner, physical controller, burns or fuel budgets.

## Findings

- 17 returns complete by1536 without a runtime/storage exception. Initial
  waiting gaps occur while Meridian phase error remains small (<.44° through512).
  Dispatch-grid aliasing, fixed14/2/14 timing, one seeded branch and no fuel-cost
  ranking explain the restricted transfer family. Failure is not a proof of
  physical infeasibility; the shooter's inscribed component cube is also more
  conservative than the engine force sphere.
- The first trip spends.444396 fuel / delta-v.775907 and dips to radius1.130238
  from an origin orbit at2. An ideal circular two-body round trip would require
  about23.496 relay dwell and delta-v.256885. These are analytical diagnostics,
  not a certified finite-burn replacement.
- Meridian's unreplenished tank approaches.1 reserve around800; controller
  failures and orbital envelope departures then account for many later stalls.
- An extra-revolution return probe yields four less expensive independent
  witnesses, but sixteen failed cases and no sequential fleet guarantee. It is
  retained as exploratory evidence, not shipped content.

## Shipped changes and checks

Immutable drawing streams are reused, admitted future samples are shared rather
than resampled onto a second grid, drawing queries are bounded/cached, and
history/chart/timeline assembly is batched at100ms. Pause synchronously assembles
the exact head before holding it; pending acknowledgement does not move that
pose. Sphere clipping fast-paths segments that miss every projected body; exact
intersection/occlusion remains in use for crossing segments. Worker ownership,
canonical dynamics, leases and bounded storage remain unchanged.

Same16× default-view profiling intervals end near512: `visibleSegment` sampled
self time4.840→.939 seconds, history-view assembly1.028→.159 seconds, idle sampled
time6.959→27.805 seconds. Observed peak main JS heap103.07→61.35MB. Both runs have
one initial Long Task (99/91ms), so this is evidence of reduced sustained display
load, not a claim that every possible hitch was reproduced/eliminated. See raw
profile files and caveats in the linked diagnosis.

Recommended next slice is bounded flexible departure/arrival/return scheduling
with economical relay dwell, including attached-mass maintenance ownership and
explicit station refueling. An Astra architecture review belongs before that
ownership change. Phase locking alone would preserve the underlying transfer
windows and does not address the early rigid-family failures.
